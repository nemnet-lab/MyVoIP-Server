1. このポリシーの対象

このポリシーは、iPhone アプリ「MyVoIP」（以下「本アプリ」）と、本アプリが接続する着信制御サーバー・Web 管理画面（以下「本サービス」）での、利用者の情報の扱いを定めます。

本アプリは、利用者または利用者の所属組織が用意した PBX（構内交換機）に接続して通話するアプリです。PBX の通話記録（CDR）や録音などの扱いは、その PBX の管理者の方針によります。

2. 取得する情報と利用目的

本サービスで扱う番号は、PBX の閉域網の中だけで使う内線番号で、一般の電話番号（0AB-J 番号など）ではありません。ただし、PBX が外線につながっている場合は、PBX が通知した外線の相手の番号が通話履歴に含まれることがあります。

運営者は、これらの情報を上の目的の範囲を超えて使いません。広告やトラッキングには使いません。

本サービスは、通話の音声を保存しません（テスト着信の録音を除く）。通話の音声は、PBX との間で中継されるだけです。

3. 端末内だけで扱う情報

  • iPhone の連絡先： 利用者が許可した場合に、発信先の選択と着信時の名前の表示に使います。サーバーには送りません。
  • アプリ内の連絡先： 端末内にだけ保存します。
  • 診断ログ： 端末内に7日分保存します。利用者が「診断情報を共有」を選んだときだけ、パスワードやトークンを伏せたうえで、利用者が選んだ方法で共有されます。自動では送信しません。

本サービスは、次の外部サービスを使います。運営者は、これらの事業者が、公表しているプライバシーポリシーに基づき、このポリシーと同等以上の保護を行っていることを確認したうえで利用します。

  • 移転先の国の個人情報の保護に関する制度：個人情報保護委員会が公表している「外国における個人情報の保護に関する制度等の調査」のとおりです。米国には、日本の個人情報保護法に相当する連邦法はなく、州法（カリフォルニア州消費者プライバシー法など）と分野ごとの法律で保護されています。

6. 安全管理措置

運営者は、利用者の情報を守るため、次の措置を講じています。

  • 組織的な措置： 運営者が責任者として、本サービスの情報の扱いを管理します。サーバーに触れられる者は、運営者と、運営者がサーバーの設置・保守を委託する協力者に限ります。
  • 人的な措置： 委託先の協力者に、このポリシーに沿った情報の扱いを守らせ、委託先として必要な監督を行います。
  • 物理的な措置： サーバーは日本国内の、委託先の協力者の住居に設置し、関係者以外が触れられないようにしています。
  • 技術的な措置： 本サービスは外部のインターネットに直接公開せず、VPN（Tailscale）のネットワーク内からだけ接続できるように運用します。SIP のパスワードは暗号化して保存し、アプリの認証に使う値は推測できないものを使い、サーバーにはそのハッシュだけを保存します。管理者が利用者の画面を開くのは、利用者が発行したサポート用パスコードを使った場合に限り、その操作は利用者の画面に記録されます。
  • 外的環境の把握： サーバーは日本国内に設置しています。外国にある第三者への提供は、5. のとおりです。

7. 同意の取り消しと、情報の削除

  • 本アプリの利用をやめる： アプリの「設定」→「ログアウト」で、端末の登録を解除できます。そのあとアプリを削除してください。
  • iPhone の登録と通話履歴を削除する： Web 管理画面で iPhone を削除すると、その iPhone の登録と、サーバー上の通話履歴が削除されます。
  • 権限を取り消す： iPhone の連絡先・マイク・通知の利用は、iPhone の「設定」→「MyVoIP」でいつでもオフにできます。
  • アカウントを削除する： 下記 8. の窓口にご連絡ください。Discord の情報・PBX の設定・残っている情報をすべて削除します。

8. 開示・訂正・利用停止・削除などのご請求

保有している情報の利用目的の通知、開示、訂正・追加・削除、利用停止・消去、第三者への提供の停止のご請求は、次の方法で受け付けます。

  • 受付方法： 電子メールのみで受け付けます（tkytel-iosapp-support@nemnet-lab.net）。件名に「個人情報に関する請求」と書き、請求の内容をお知らせください。
  • 本人確認： Web 管理画面にログインしている Discord アカウントからのご連絡、または Web 管理画面で発行したサポート用パスコードで、ご本人であることを確認します。
  • 手数料： かかりません。
  • 回答： 本人確認ができたあと、遅滞なく電子メールで回答します。
